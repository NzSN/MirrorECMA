# Shared orchestration implementation and acceptance

This ledger tracks the implementation of
[the shared orchestration design](shared-orchestration-design.md). Local
working-tree validation, hosted CI, and released package compatibility are
separate evidence. An incomplete or unavailable required gate is not a pass.

## Ownership

All implementation assignments use the `fullstack-developer` role. The
coordinator owns independent review, final validation, and this ledger.

| Assignment | Owned implementation | Required evidence |
| --- | --- | --- |
| Async replay | Shared negotiation/replay internals, exact async registry, structured reports, bounded model-transport closure | Legacy compatibility, synchronous microtask encoding, async ordering/cancellation, failure precedence |
| Async compiler | Mirrors async TypeScript emitter and target dispatch, compiler-owned Counter output | Real compiler freshness/preflight, old-target byte identity, generated binding compilation and execution |
| Native TypeScript facade | MirrorECMA sandbox entry point, verified model/native proxy, optional SDK packaging, tests/examples | Required match before authorization/launch, private-data boundary, owned/attached cleanup, correct/faulty real replay |
| Shared acceptance | Gate public integration helpers, native MirrorCPP integration, shared acceptance driver | Native model negotiation and genuine Mirrors mismatch across worker runtimes and control modes |

Existing uncommitted MirrorGate control implementation and unrelated scratch
files are preserved. The native C++ SDK's existing local Counter comparison
does not by itself establish model-facing cross-client acceptance.

## Review findings resolved

- Preserved immediate synchronous encoding, legacy registration diagnostics,
  and compiler-owned synchronous bytes.
- Added monotonic deadline enforcement, late-promise handling, factory-scope
  cancellation, post-await checks, and cleanup-error retention.
- Corrected fixed disclosure/model snapshots without freezing caller-owned
  transports; verified Unicode-safe bounded diagnostics and failure families.
- Fixed model-process cleanup being incorrectly reported as confirmed.
- Made C++ owned-controller shutdown confirmation observable and authoritative
  for the overall result, while preserving the existing `noexcept close()` API.
- Replaced a load-sensitive C++ transport-test sleep with explicit peer closure
  and exception-safe thread joining, including failure before connection.
- Verified pnpm 11 configuration in `pnpm-workspace.yaml` and the lockfile using
  a clean install; the optional Gate peer stays absent from ordinary installs.

and [CI entry script](../tools/ci/shared-orchestration.sh) require explicit
companion commits and a prepared self-hosted Linux/Bubblewrap runner. YAML and
shell validation passed. No hosted CI run or package publication was performed;
the public profile remains experimental until those distribution gates are met.

## Follow-up: fresh restricted authoring

The [fresh Counter authoring experiment](../experiments/blind-counter/results/2026-09-08/REPORT.md)
subsequently started from an empty submission and used an isolated author with
only Gate-mediated tools. The source was written, publicly tested, frozen,
built, and privately evaluated successfully: four traces, four initializations,
36 ticks, one worker, and confirmed cleanup. This follow-up added public bounded
authoring stdout/stderr and corrected a generated deadline timer edge case.
Its final MirrorECMA regression suite passed 340/340 tests, and the Mirrors gate
passed again. These results supplement the earlier 42-case integration matrix;
private evaluation inputs remain unarchived.
