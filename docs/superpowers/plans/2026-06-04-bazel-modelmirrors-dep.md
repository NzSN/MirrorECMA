# ModelMirrors as Bazel Module Dependency — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add ModelMirrors as a bzlmod dependency so `bazel test //:smoke` builds the binary from source and runs the smoke test hermetically.

**Architecture:** Three-layer change: (1) `MODULE.bazel` gains a `bazel_dep` + `git_override` for `modelmirros`, (2) a new `scripts/smoke_bazel` wrapper receives the binary path and runs jest, (3) a `sh_test` rule in `BUILD.bazel` wires them together with `$(rootpath)`.

**Tech Stack:** Bazel 8.7.0 (bzlmod), shell, existing jest/ts-jest test harness.

---

## File Structure

| File | Action | Responsibility |
|------|--------|----------------|
| `MODULE.bazel` | Modify | Declare `modelmirros` dependency with git override |
| `scripts/smoke_bazel` | Create | Thin shell wrapper: sets `MIRROR_BIN=$1`, runs `npx jest` |
| `BUILD.bazel` | Modify | Add `sh_test` target wired to `@modelmirros//app:ModelMirros` |
| `AGENTS.md` | Modify | Document `bazel test //:smoke` command |

All other files (`src/*`, `test/smoke.test.ts`, `jest.config.ts`, `scripts/smoke`) are unchanged.

### Task 3: Add sh_test target to BUILD.bazel

**Files:**
- Modify: `BUILD.bazel`

- [ ] **Step 1: Add sh_test rule after the existing genrule**

Append to `BUILD.bazel`:

```python
sh_test(
    name = "smoke",
    srcs = ["scripts/smoke_bazel"],
    args = ["$(rootpath @modelmirros//app:ModelMirros)"],
    data = [
        "@modelmirros//app:ModelMirros",
        "test/smoke.test.ts",
        "specs/Counter.tla",
        "package.json",
        "jest.config.ts",
        "tsconfig.json",
    ],
    tags = ["local", "no-sandbox"],
    env = {"NODE_OPTIONS": "--experimental-vm-modules"},
)
```

Full `BUILD.bazel` becomes:

```python
genrule(
    name = "lib",
    srcs = glob(["src/**/*.ts"]) + [
        "tsconfig.json",
        "package.json",
    ],
    outs = [
        "index.js",
        "index.d.ts",
        "protocol.js",
        "protocol.d.ts",
        "client.js",
        "client.d.ts",
        "transport.js",
        "transport.d.ts",
    ],
    cmd = """
        WS=$$(dirname $$(realpath $(execpath package.json)))
        "$$WS"/node_modules/.bin/tsc \
            --project "$$WS"/tsconfig.json \
            --outDir $(RULEDIR) \
            --rootDir "$$WS"/src
    """,
    tags = ["local", "no-sandbox"],
)

sh_test(
    name = "smoke",
    srcs = ["scripts/smoke_bazel"],
    args = ["$(rootpath @modelmirros//app:ModelMirros)"],
    data = [
        "@modelmirros//app:ModelMirros",
        "test/smoke.test.ts",
        "specs/Counter.tla",
        "package.json",
        "jest.config.ts",
        "tsconfig.json",
    ],
    tags = ["local", "no-sandbox"],
    env = {"NODE_OPTIONS": "--experimental-vm-modules"},
)
```

Expected: Bazel builds `@modelmirros//app:ModelMirrors` (incremental if already built in Task 1), runs the jest smoke test via the wrapper script, and reports PASS. The test output should show the Counter.tla end-to-end trace replay succeeding.
